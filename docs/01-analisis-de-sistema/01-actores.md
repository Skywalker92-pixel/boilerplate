# Identificación de Actores del Sistema

Los actores representan a las personas, roles y sistemas externos que interactúan con el Marketplace de productos para mascotas desde fuera de sus límites.

## 1. Actores Humanos

| Actor | Descripción y responsabilidades en el sistema |
| :--- | :--- |
| **Cliente** | Busca productos, consulta información, gestiona el carrito de compras, realiza pedidos, procesa pagos y realiza seguimiento a sus órdenes. |
| **Seller (Vendedor)** | Registra y actualiza su catálogo de productos, administra stock, consulta sus ventas y gestiona la información comercial de su tienda. |
| **Administrador** | Gestiona la plataforma, supervisa y aprueba el registro de sellers, y monitorea la operación global del marketplace[cite: 1]. |

## 2. Sistemas Externos

| Sistema Externo | Rol en la integración |
| :--- | :--- |
| **Pasarela de pago** | Procesa de forma segura las transacciones de pago electrónico generadas por los clientes[cite: 1]. |
| **Servicio de envío** | Gestiona la logística, tarifas de entrega y el seguimiento del despacho físico de los pedidos[cite: 1]. |
| **Servicio de Facturación** | Emite comprobantes de pago electrónicos conforme a las regulaciones tributarias[cite: 1]. |
| **ERP** | Proporciona y sincroniza información externa de productos, inventario centralizado y contabilidad[cite: 1]. |
