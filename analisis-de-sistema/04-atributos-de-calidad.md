# Atributos de Calidad

Los atributos de calidad definen las propiedades operativas y estructurales de la solución, determinando cómo debe desempeñarse el marketplace ante escenarios críticos de uso[cite: 1].

## Escenario de Referencia
Durante una campaña comercial (por ejemplo, Cyber Days o campañas de ofertas para mascotas), el marketplace experimenta un pico masivo de usuarios concurrentes navegando el catálogo, gestionando carritos y realizando compras de manera simultánea[cite: 1].

---

## Matriz de Atributos y Escenarios de Calidad

| ID | Atributo de Calidad | Escenario de Calidad |
| :--- | :--- | :--- |
| **AC01** | **Rendimiento** | Las consultas de productos y las operaciones del carrito deben responder rápidamente (baja latencia) incluso bajo alta concurrencia de usuarios[cite: 1]. |
| **AC02** | **Disponibilidad** | El sistema debe permanecer operativo y tolerante a fallos durante toda la campaña comercial, garantizando transacciones sin caídas[cite: 1]. |
| **AC03** | **Escalabilidad** | La plataforma debe ser capaz de soportar un incremento sustancial de usuarios y solicitudes sin degradar significativamente su funcionamiento[cite: 1]. |
| **AC04** | **Seguridad** | La información sensible de los usuarios, credenciales, sesiones y operaciones de compra deben estar protegidas contra accesos no autorizados e intercepciones[cite: 1]. |
| **AC05** | **Mantenibilidad** | El sistema debe diseñarse desacoplado para permitir cambios, mejoras y correcciones sin afectar de forma imprevista otros módulos o funcionalidades[cite: 1]. |
