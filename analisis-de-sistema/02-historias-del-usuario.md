# Historias de Usuario

A continuación se definen las historias de usuario que describen las principales necesidades de interacción en el Marketplace[cite: 1]:

| ID | Historia de Usuario | Criterio de Aceptación General |
| :--- | :--- | :--- |
| **HU01** | **Como** cliente, **quiero** buscar y consultar productos, **para** encontrar el producto que necesito[cite: 1]. | El cliente puede filtrar por categoría, nombre y ver stock disponible[cite: 1]. |
| **HU02** | **Como** seller, **quiero** registrar y gestionar mis productos, **para** ofrecerlos a los clientes en la plataforma[cite: 1]. | El seller puede crear, editar precio, descripción e imagen de sus productos[cite: 1]. |
| **HU03** | **Como** cliente, **quiero** gestionar los productos de mi carrito, **para** preparar los artículos que deseo comprar[cite: 1]. | Permite añadir, remover y actualizar cantidades recalculando subtotales[cite: 1]. |
| **HU04** | **Como** cliente, **quiero** realizar un pedido con los productos de mi carrito, **para** completar mi compra[cite: 1]. | Genera la orden vinculando dirección de entrega y método de pago[cite: 1]. |
| **HU05** | **Como** administrador, **quiero** gestionar los sellers de la plataforma, **para** administrar y supervisar a los vendedores registrados[cite: 1]. | Permite activar, suspender o dar de alta perfiles comerciales de sellers[cite: 1]. |
| **HU06** | **Como** cliente, **quiero** consultar mis pedidos y su estado, **para** conocer el avance y entrega de mis compras[cite: 1]. | Muestra un historial detallado de pedidos con estados (ej. pagado, despachado, entregado)[cite: 1]. |
